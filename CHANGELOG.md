# Changelog

## 0.1.0

Initial T4 Studio packaging preparation.

- Rebranded NuGet package identity to `T4Studio.Engine`, `T4Studio.Cli`, and `T4Studio.Build`.
- Kept existing `T4Studio` namespaces and assemblies for compatibility.
- Added package metadata, README packaging, symbols, and repository metadata.
- Added documentation for getting started, packaging, and release flow.
- Added GitHub Actions workflows for CI packaging and tag-based NuGet publishing.
- Rebranded editor extension metadata for T4 Studio.

Existing `.tt` templates remain supported.
